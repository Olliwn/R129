# nRF5430 Interface Board SPICE Design

**Date:** 2026-03-26
**Session ID:** 1671a408-8e8c-46dd-a779-5c0a6f174fb7

## Summary

Deep session on the nRF5430 diagnostic interface board design. Counted diagnostic
channels from the ADS blink-reader work, chose ngspice as the simulator, and built
opto-isolator and car-side equivalent circuit models with netlists, test benches, and
a simulation plan.

Follow-on work covered netlist viewing (Python `netlist_viewer` parse errors), HTML
schematic feedback (labels, domain boxes, Rload, car vs. board regions), updating
netlists and re-running simulations. Moved to breadboard build instructions, Stage 1
bring-up plan, solderable breadboard (PTS-00079) selection, component inventory under
`/components`, and SP Elektroniikka parts vs. BOM comparison.

Later topics included Q_EN / IRF5305 MOSFET selection, wiring clarity, OKI-78SR vs
LD1117 voltage regulator options, powering the nRF5430 DK from the board in the
engine bay (no USB), and 1N4007 current rating verification.
